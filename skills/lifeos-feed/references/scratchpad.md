# Scratchpad

End every task with one scratchpad. Chained stages add rows to one running scratchpad, emitted once at the end. Facts only; omit empty sections.

```
### Scratchpad: <Visible Name> v<version>
**Scope:** <what was run>

| # | Request | Status | Context |
|---|---|---|---|
| 1 | <one request, user's words> | <done / partly done / in progress / failed / not started / needs you> | <result, blocker or what is left> |

**Changed:** <files or records, one line each>
**Flags:** <failures, assumptions, unresolved items>
**Next:** <single next action>
```

One row per request, including added, declined and deferred ones.
